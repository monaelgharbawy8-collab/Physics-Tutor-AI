# Physics Tutor AI

An AI-powered Physics Learning Assistant built with Streamlit and Google Gemini.

The application helps students understand physics concepts through detailed explanations, formulas, real-world examples, and practice questions.


## Features

* Explain Physics concepts in simple language
* Display relevant formulas
* Provide detailed step-by-step explanations
* Generate real-world examples
* Create practice questions for self-assessment
* Maintain conversation history using Streamlit Session State
* Interactive web interface built with Streamlit


## Technologies Used

* Python
* Streamlit
* Google Gemini API
* Prompt Engineering
* Session State Management
* Git & GitHub

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/Physics-Tutor-AI.git
```

Navigate to the project folder:

```bash
cd Physics-Tutor-AI
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate the environment:

### Windows

```bash
venv\Scripts\activate
```

### Linux / Mac

```bash
source venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## Environment Variables

Create a `.env` file:

```env
GEMINI_API_KEY=YOUR_API_KEY
```

##  Run the Application

